# Ясно яно егэ бот
***
Репозиторий состоит из бота предназначенного для записи на консультации по учебе, и записи на экскурсии и программы для удаления "просроченных" событий из базы данных
# Запуск 
***
1. Запуск бота производится с помощью команды poetry run path/to/Yasno_yasno_ege_bot/tg_bot -m path_to.env
2. Запуск программы для удаления "просроченных" событий производится с помощью poetry run path/to/Yasno_yasno_ege_bot/event_deleter -m path_to.env
